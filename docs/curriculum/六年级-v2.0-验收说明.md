# 六年级 v2.0 验收说明

验收日期：2026-10-04。对应v2.0源码；Git推送和线上部署状态须另行验证。

## 教材与内容

六上基于国家平台北师大版2026年7月第1版、2022课标修订教材原页，13模块顺序逐项一致。六下依平台当前公开教材的7模块完整重写，不把网站版本号说成新版教材版本。来源、正文课题与每模块覆盖分别记录在两册教材核对说明。

共20模块、86项知识讲解、60个生活例、200道闯关题、80步解题过程、20个活动。上下册各一次50题考试，由本册所有模块轮换取题。原创SVG知识图解31种，可播放/暂停、手动前后步进、重播；练习附图不显示冲突数值或答案。

两册课程数据由不同于作者的审查者逐项手算：题目答案、数值、单位、正确下标、选项唯一性与条件齐全性复核通过。补齐六下莫比乌斯带和数对伸缩，并修正圆锥装满水/空容器、三角形共边串、圆形花坛、单位“1”和活动分类的互斥条件。

## 图解复核

独立审查者实际查看圆面积扇形拼图、莫比乌斯带示意、小猫数对变形和手机图解。圆拼图按扇形半弦与高度交错，近似长πr、宽r；莫比乌斯剪后图明示结果示意；横纵数对变换与图形对应。中性题图不包含演示例题条件，避免题图误读。
