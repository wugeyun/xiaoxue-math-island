# 小小数学岛建设与扩建规范

“小小数学岛”是面向小学三至六年级孩子的北师大版数学趣味自学平台。项目采用纯 HTML、CSS、JavaScript 实现，不依赖框架、构建工具或后端服务。三至六年级上下册现已全部完成，后续维护应继续保持相同的视觉风格、学习结构、技术方案和教材核对标准。

## 在线演示

[打开 Vercel 演示站点](https://xiaoxue-math-island.vercel.app/)

## 目录布局

根目录只保留网站总入口和项目说明，课程页面、通用资源、分册数据与教材核对文档按职责分层：

```text
index.html                         网站总入口
courses/                            八册课程页面
assets/css/                         总入口与课程页样式
assets/js/core/                     通用交互、页面骨架、考试逻辑
assets/js/data/<册次>/              各册课程数据
docs/curriculum/                   教材核对说明
README.md                           项目建设与维护规范
```

课程页面统一从 `../assets/` 加载资源，并从 `../index.html` 返回教材大厅；Vercel 的 Root Directory 仍保持为仓库根目录。

- 入口首页覆盖三年级至六年级上、下册，共 8 个教材入口。
- 三至六年级上、下册共 8 册均已开放。
- 三年级上册共 12 个学习模块：8 个单元、3 个实践探索模块和 1 个整册复习模块。
- 三年级下册共 11 个学习模块：7 个单元、2 个综合实践模块、1 个数学好玩和 1 个整册复习模块。
- 每个模块固定包含 5 个学习关卡、3 个生活应用例子和 10 道闯关题。
- 每册学习地图末尾增加 1 次整册考试；每次考试 50 题，每题 2 分，满分 100 分。
- 全平台共 81 个学习模块、405 个互动关卡、243 个生活应用例子、810 道闯关题和 8 次整册考试（400 道考试题）。
- 全平台课程与考试题目合计 1210 道；整册考试按单元轮换抽题，确保每册全部模块都有覆盖。
- 学习进度保存在浏览器 `localStorage` 中，不需要账号或服务器数据库。

## 二、建设目标

平台首先服务于第一次接触知识点的孩子。设计时必须做到：

1. 先帮助孩子理解，再要求孩子计算或记忆。
2. 一屏只处理一个主要任务，说明短、按钮清楚、反馈及时。
3. 用动画感、动手操作、分步提示、生活情境和即时测试降低学习门槛。
4. 允许答错，错误反馈给方向或方法提示，不使用责备性语言。
5. 内容贴近校园、购物、出行、时间、测量、游戏等真实生活。
6. 页面用语采用“基础入门”“不会没关系”等儿童友好表达，不使用“小白友好”等网络化标签。

## 三、统一学习结构

每个模块固定采用以下五步，不随年级改变：

1. **看动画**：用故事、图形和动态视觉引出一个核心知识点。
2. **动手做**：通过分组、选择、数值构造、硬币等互动亲手发现规律。
3. **分步解**：把解题过程拆成连续的小步骤，每一步说明“为什么”。
4. **生活练**：连续完成 3 个不同生活场景的应用例子。
5. **闯关测**：完成 10 道题；第一题作答前，页面最右上角原有星星数字位置显示上一次完整闯关成绩；开始作答后从 100 分实时计分，每选错一次扣 1 分；中途退出不保存本次临时分数，完成全部题目后才保存并更新成绩。

每册学习模块之后另有一次**整册考试**：共 50 道题，每题 2 分，开始时右上角显示 100 分；每道题首次答错扣 2 分，同一道题再次尝试不重复扣分；完成 50 题后才保存本次成绩，中途退出不保存临时成绩。考试题从本册各模块的完整题目中按单元轮换抽取，覆盖每个模块。

课程题和整册考试题必须可以脱离上一题独立理解。题干要写出完整条件、问题、数字和单位，不得使用“这道题”“上一题”“上述内容”等上下文指代；每题都必须对应明确知识点或真实应用，不能使用“学习时首先做什么”“关键表达是什么”等没有具体情境的凑数题。

生活练、单元闯关和整册考试答错时，红色提示必须给出完整解题思路：审题找条件、找数量或图形关系、按顺序计算或判断、带回原题检查数值和单位；提示可以不直接指出最终选项，但不能只说“再试一次”。

生活练不能只让孩子选择一条抽象规则。题面必须给出具体的人物、物品、数量或图形条件；选项应落到具体算式、操作或结论。答对后统一按“找条件 → 找关系 → 列式或作图 → 回到情境检查”的顺序展示完整思路。例如讲分数除法时，应写出 `3/4÷3=3/4×1/3=1/4`，不能只停留在“除以一个数等于乘它的倒数”的文字背诵。

课程数据中的分数继续使用 `3/4` 等斜杠形式保存，便于编写和检查；页面显示时由 `app.js` 自动排成分子在上、分母在下并带横线的标准分数。进度 `0/5`、例子序号 `1/3`、测试得分等状态数字不是数学分数，必须保留斜杠显示。

每完成一步点亮 1 个关卡并获得 1 颗星。一个模块完成 5 步后，在课程地图和侧栏中显示完成状态。

## 四、视觉与交互风格

### 视觉基调

- 使用温暖的米白背景、珊瑚红主按钮，以及蓝、绿、黄、紫等明快辅助色。
- 采用圆角卡片、柔和阴影、较大的标题和按钮，避免密集、严肃的练习册视觉。
- 用数学岛、路线、星星、小动物和生活物品形成冒险感。
- 优先使用 CSS 图形和 Emoji，保持页面轻量，不依赖外部图片资源。
- 每个模块有独立主题色，但导航、按钮和反馈方式保持一致。

### 交互原则

- 正确答案使用绿色反馈，展示完整分步思路；答对后必须点击“下一题”，不自动跳题。
- 错误答案使用红色反馈，展示完整审题、列式/作图、计算和检查思路；错误选项禁用但保留其他选项供重试。
- 整册考试固定50题，每题2分，满分100分；首次答错扣2分，实时分数显示在右上角，答题后手动点击“下一题”。
- 下一步按钮在必要操作完成前保持禁用，防止无意跳过。
- 分步解题必须按顺序解锁，不能一次展示全部答案。
- 兼顾桌面与移动端：桌面显示侧栏，窄屏使用课程目录按钮。
- 交互元素使用原生 `button`、`a`、`role`、`aria-label` 等语义，便于键盘操作和页面测试。

## 五、技术方案

### 技术栈

- HTML5：页面结构和语义。
- CSS3：响应式布局、插画、过渡和庆祝动画。
- 原生 JavaScript：数据渲染、交互、答题、进度和本地存储。
- Python 静态服务器：本地预览。

项目不引入 npm 依赖、前端框架、数据库或接口。教材内容与交互数据全部保存在本地 JavaScript 文件中，因此打开快、迁移简单，也便于逐册独立核对。

<script src="../assets/js/data/grade3-up/course-data.js"></script>
<script src="../assets/js/data/grade3-up/course-enhancements.js"></script>
<script src="../assets/js/core/app.js?v=15"></script>

### 单元数据结构

每个 `courseUnits` 项必须包含以下字段：

```js
{
  id: '唯一英文标识',
  number: '单元编号或实/趣/复',
  title: '模块名称',
  icon: '主题图标',
  subtitle: '教材内容摘要',
  color: '#主题色',
  lessonTitle: '儿童化课程标题',
  lessonSubtitle: '准确的学习目标',
  story: { label, title, text, equation, rule, art },
  activity: { type, title, text, /* 互动类型所需字段 */ },
  solver: { equation, steps: [[步骤名, 算式或结论, 原因说明]] },
  life: { icon, title, story, question, options, answer, explain },
  quiz: [[题干, [选项1, 选项2, 选项3], 正确选项下标, 提示]]
}
```

当前支持的动手互动类型：

- `group`：逐个放置物品并完成平均分或分组。
- `choice`：观察或判断后选择答案。
- `pattern`：发现规律并选择下一项。
- `calendar`：观察日历或时间信息。
- `builder`：用加减按钮构造目标数。
- `coins`：使用硬币凑出目标金额。

新增内容优先复用这些类型。只有教材目标确实无法表达时，才增加新的互动类型，并同时补充 `app.js` 渲染、反馈、重置和完成逻辑。

### 进度存储

`app.js` 使用 `localStorage` 保存每个模块已完成的关卡和最高测试成绩。每个新册次必须使用独立的存储键，避免不同教材的进度互相覆盖，例如：

```js
const STORE_KEY = 'mathIslandG3Down2022VerifiedV1';
```

册次、教材版本或数据结构变化时应升级键名末尾版本号。正式交付前使用新键重新加载页面，确保不会带入测试进度。

## 六、教材核对要求

教材核对是扩建前置步骤，不能凭印象、旧目录或搜索摘要直接制作。

### 必须使用的依据

1. 优先使用国家中小学智慧教育平台上的对应北师大版教材。
2. 确认年级、上/下册、出版社和课程标准修订版本完全一致。
3. 记录官方页面链接与核对日期。
4. 查看教材目录和相关正文，逐项确认单元、课题、综合实践、数学好玩和总复习内容。
5. 为每一册建立独立的“教材核对说明”文档，不覆盖已有册次记录。

三年级上册当前核对依据见 [docs/curriculum/教材核对说明-三年级上册.md](docs/curriculum/教材核对说明-三年级上册.md)。

### 内容边界

- 必须保持教材规定的知识范围、核心概念、运算规则、学习顺序和难度层级。
- 可以重写人物、数字、故事、插图和练习，但不能改变知识目标或引入超出本册要求的方法。
- 不直接复制教材页面、插图、长段文字或原题；应用中的表达必须重新创作。
- 生活题的数据要合理，答案必须唯一，单位和表述必须准确。
- “整册复习”只能综合本册已经出现的知识，不提前加入后续年级内容。
- 首页预告文案也要在核对相应教材后再定稿；未核对的内容只写概括性状态。

### 每个模块的核对记录

制作前至少记录：

- 教材模块名称与包含课题。
- 本模块核心知识点和不应越界的内容。
- 适合制作动画、动手互动和分步解题的切入点。
- 3 个生活例子的知识对应关系。
- 10 道题覆盖的知识点与难度分布。

建议题量分布为：6 道基础理解与计算、3 道生活应用、1 道易错辨析或综合题。低年级仍以三选一、短题干和单一目标为主。

## 七、新册次扩建流程

以“三年级下册”为例，按以下顺序执行：

1. 在官方平台找到正确教材，完成目录和正文核对。
2. 新建独立核对文件，例如 `教材核对说明-三年级下册.md`。
3. 列出全部单元、综合实践、数学好玩和整册复习模块，确定模块总数。
4. 为每个模块写清核心目标、内容边界和五步学习设计。
5. 在 `courses/` 下复制课程页骨架，命名为 `grade3-down.html`，更新标题、地图文案和册次标识。
6. 在 `assets/js/data/grade3-down/` 下新建 `course-data.js` 和 `course-enhancements.js`。
7. 保持每模块“1 个核心故事、1 个动手互动、1 套分步解题、3 个生活例子、10 道题”的标准。
8. 为该册配置独立 `localStorage` 键；若继续复用 `app.js`，先将存储键和册次文案改为可配置值，且不得影响已完成的三上页面。
9. 在 `index.html` 中把对应教材卡片改为可点击的“已开放”，并更新模块、关卡和题量统计。
10. 完成内容检查、代码检查和浏览器全流程验收后再交付。

## 八、验收标准

### 内容验收

- 教材版本、目录和课题已从官方教材逐项核对。
- 模块数量和顺序与教材一致，实践内容没有遗漏。
- 每模块恰好有 3 个生活例子和 10 道闯关题。
- 每册整册考试恰好有 50 道题，覆盖本册每个学习模块。
- 所有题目答案、计算、单位和正确选项下标均复核无误。
- 每道题脱离上一题仍能独立理解，题干不含上下文指代或空泛学习方法问答。
- 内容是原创改写，没有直接复制教材页面或原题。
- 表达适合对应年龄，既不过难，也不幼稚化。

### 功能验收

- 首页、教材页和返回链接均可访问。
- 课程目录、学习地图和所有模块均能打开。
- 五个关卡都能完成，禁用与解锁状态正确。
- 3 个生活例子会按顺序出现，完成第 3 个后进入闯关。
- 闯关正确显示“第 1 题 / 共 10 题”，先在绿色区域显示完整思路，点击“下一题”后才进入下一题，10题后进入成绩页。
- 第一题未作答时，页面最右上角显示上一次完整闯关成绩；第一次作答时，本次从 100 分开始计分，错选一次立即变为 99 分并同步显示扣分提示；中途退出再进入仍显示上一次成绩；完成 10 题后才保存本次成绩；测试区内不额外显示分数卡片。
- 正误提示均包含完整解题思路，答错后仍可重试，答对后不会自动跳题。
- 星星、单元进度和整册进度保存正确。
- 刷新后进度仍在；使用新存储键后初始进度为 0。
- 桌面端和移动端均无横向溢出，按钮易点击，文字不遮挡。
- 浏览器控制台没有 JavaScript 错误，所有本地资源请求成功。

### 建议检查命令

在项目目录执行：

```bash
node --check assets/js/data/grade3-up/course-data.js
node --check assets/js/data/grade3-up/course-enhancements.js
node --check assets/js/core/app.js
rg -n "小白|6道|6题|1个生活" . --glob '!README.md' --glob '!tmp/**'
```

其中最后一条命令应无结果。新增册次后，把文件名替换为对应数据文件，并增加数据数量检查，确保每个模块满足 `lifeExamples.length === 3` 和 `quiz.length === 10`，每册整册考试满足 50 道题、每题 3 个选项且正确选项下标有效。

## 九、本地运行

在项目目录运行：

```bash
python3 -m http.server 2103 --bind 127.0.0.1
```

然后访问：

- 教材总入口：<http://127.0.0.1:2103/>
- 三年级上册：<http://127.0.0.1:2103/courses/grade3-up.html>
